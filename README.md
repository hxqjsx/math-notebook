# 《数学奇妙笔记本》配套动画
### Nonstandard Notebook · Interactive Animations

我是胡小群，是《数学奇妙笔记本》的中文译者。本书中文版以“胡小群讲数学团队”署名翻译，这个项目是我为书中图案制作的配套动画。

本书的英文原名是 **Nonstandard Notebook: Mathematically Ruled Pages for Unruly Thoughts**，由 **Tim Chartier（蒂姆·查蒂尔）** 和 **Amy Langville（埃米·兰维尔）** 合著。[英文原版介绍](https://press.uchicago.edu/ucp/books/book/chicago/N/bo230146731.html)

## 为什么做这些动画

在翻译和阅读这本书的过程中，我一直觉得，书里的很多图案如果能动起来，就更容易看懂。

一组简单的直线，为什么会形成复杂的图案？改变一个参数，图形会发生什么变化？那些看起来很特别的曲线，是怎样一步步画出来的？

书上的静态图案展示了结果，我希望这些动画能把生成的过程也呈现出来。你可以一边看书，一边播放、暂停或拖动进度，对照公式和参数，观察图案怎样逐渐形成。

## 可以看到什么

目前包含全书 **12 章、174 个图案页面**，支持：

- 按章节、图案和原书页码查找内容。
- 对照静态图案，观看动态绘制过程。
- 播放、暂停、重新开始和调整播放速度。
- 拖动进度，观察不同阶段的图形。
- 结合公式和参数理解作图过程。

电脑和手机浏览器均可使用。

**[点击体验配套动画](https://hxqjsx.github.io/math-notebook/)**

这些动画适合配合原书阅读，也欢迎老师在课堂上演示，或者和孩子一起观察、讨论。

## 关于开源

这个项目从 **v24** 开始公开源码。我希望它能方便更多人理解和欣赏书中的数学，也欢迎大家提出问题、改进交互，或参与代码维护。

公开仓库包含当前版本的源码和必要构建文件，不包含原书 PDF。

## 本地运行

需要 Python 3.10 或更新版本；运行自动检查还需要 Node.js 20 或更新版本。

下载或克隆本仓库后，在项目目录运行：

```sh
python3 scripts/build.py
```

构建完成后，打开 `dist/index.html` 即可浏览。

运行自动检查：

```sh
python3 scripts/check.py --skip-build
```
